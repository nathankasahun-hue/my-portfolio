# Portfolio Image Guide

Replace these files with your own images to update the portfolio automatically.
You do NOT need to edit any HTML, CSS, or JavaScript files.

---

## Profile Photo

**Current file:** `image.png`

Replace `assets/images/image.png` with your professional headshot.
- Recommended format: JPG, PNG, or WEBP
- Recommended ratio: Portrait (e.g. 4:5 or 3:4)
- Minimum size: 600 × 750 px

## Important Notes

- Keep the **exact same filenames** when replacing images.
- The website will automatically use your new image without any code changes.
- If an image file is missing, the website will show a clean placeholder automatically.
- SVG placeholder files (ending in `.svg`) are fallbacks — do not delete them.

---

## To change the filename (optional)

If you want to use a different filename, open `js/data.js` and update
the `personal.images` object at the top of the file. All image paths
are centralized there.
